## Problem

There is no repository. Before any of the interesting rules can be enforced there has to be a
place to enforce them: a backend that starts, a frontend that builds, a local database that
matches production, and a pipeline that runs on every pull request.

The risk this addresses is the usual one for a solo portfolio project - the harness gets added
last, after the habits have already formed, and by then the coverage gate is embarrassing to
switch on and the spec files are written retroactively to match whatever was built. Turning the
gates on while the project is empty costs nothing and makes them non-negotiable afterwards.
