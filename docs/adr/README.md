# Architecture Decision Records

One file per decision that was expensive to make and would be expensive to
reverse. Numbered, immutable once accepted: a decision that changes gets a new
ADR that supersedes the old one rather than an edit.

Not everything needs an ADR. If the answer is obvious to the next reader from
the code, skip it.
